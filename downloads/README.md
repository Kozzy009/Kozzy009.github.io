# 高校入試コーチ — はじめにお読みください

**個人端末版 v0.2.1 ／ 操作説明更新：2026年9月15日**

5教科の成績や学習状況を記録して、次の一週間の学習計画を考えるためのアプリです。全国の中学生・家庭で利用できます。合否や能力を判定するものではありません。

**ダウンロード → ZIPを展開 → 起動ファイルを開く →「1」を入力**が基本の流れです。初めて使うパソコンには、先に「Node.js」という動作に必要なソフトを入れてください。

## まず確認してください

| 項目 | この版の内容 |
| --- | --- |
| 対象 | パソコン用。スマホ版は未対応です。 |
| Mac | 動作確認済みです。初回に実行権限や安全確認の操作が必要な場合があります。 |
| Windows | 起動ファイルを用意しています。Windows実機での動作確認は未実施です。 |
| 必要なソフト | Node.js 24以上と、同梱のnpm。アプリのZIPには含まれていません。 |
| インターネット | 初回設定・更新・外部AIの利用時に必要です。通常の記録・分析・計画はオフラインでも使えます。 |
| アカウント | このアプリへの会員登録は不要です。 |
| 保存場所 | 学習データは自分のパソコンに保存します。他の利用者へ自動共有しません。 |

## 初めて使うとき

### 1. Node.jsを入れる

[Node.js公式ダウンロードページ](https://nodejs.org/ja/download)から、自分のパソコン用の**バージョン24以上**をインストールします。npmも一緒にインストールしてください。すでに導入済みの場合は、この作業は不要です。

インストール後、開いている起動ウィンドウがあれば閉じて、開き直してください。

### 2. ZIPをダウンロードして展開する

HPから `exam-coach-personal-v0.2.1.zip`（または `exam-coach-personal.zip`）をダウンロードします。

- **Windows：** ZIPを右クリックし、「すべて展開」を選びます。
- **Mac：** ZIPをダブルクリックします。

展開してできた **`exam-coach` フォルダ全体**を使います。中の起動ファイルだけを別の場所へ移動しないでください。ZIPの中から直接起動することもできません。

### 3. 自分のパソコン用の起動ファイルを開く

| パソコン | ダブルクリックするファイル |
| --- | --- |
| Windows | **高校入試コーチ.cmd** |
| Mac | **高校入試コーチ.command** |

Macで開けない場合は、下の[Macで起動を許可する方法](#macで起動を許可する方法)を確認してください。

### 4. メニューで「1」を選ぶ

文字が表示されるウィンドウが開きます。これを、この説明では「起動ウィンドウ」と呼びます。Macではターミナルが開きます。

```text
1: 起動  2: 初回設定・更新  3: バックアップ  4: 復元  5: 保存先を表示
番号:
```

半角の **`1`** を入力して、Enterキーを押してください。

初回は必要なプログラムの準備を自動で行います。ネット接続を保ち、完了するまでウィンドウを閉じずに待ちます。パソコンや回線によって数分以上かかります。途中で英語が表示されても、すぐに失敗とは限りません。

### 5. ブラウザが開いたら準備完了

「起動しました」と表示され、ブラウザにホーム画面が開きます。自動で開かない場合は、表示されたアドレスをブラウザへコピーしてください。

```text
起動しました: http://127.0.0.1:3001
```

このアドレスは例です。**そのとき自分の起動ウィンドウに表示されたアドレス**を使ってください。

## 毎日の起動と終了

### 起動する

起動ファイルをダブルクリックし、メニューで **`1` → Enter** を押します。初回設定が済んでいれば、そのまま起動します。

**起動ウィンドウは、アプリを使っている間は閉じないでください。** 最小化しておくことはできます。

### 終了する

1. 入力中の内容を、画面の「保存」「登録」などのボタンで保存します。
2. 起動ウィンドウに戻ります。
3. 「終了するにはEnterを押してください」と表示されているところで、Enterキーを押します。
4. アプリが停止し、「終了時バックアップ」が表示されるまで待ちます。
5. Macでは「Enterキーで閉じます」と出たら、もう一度Enterを押します。Windowsでは表示に従ってキーを押して閉じます。

ブラウザを閉じるだけでは、アプリは終了しません。強制終了や電源断の場合は、終了時バックアップが作られないことがあります。

### ポート番号の設定は不要です

「ポート」は、パソコン内でアプリを区別するための番号です。v0.2.1では、3000番が使用中でも**空いている番号を自動で選びます**。

番号が変わっても、保存した学習データは変わりません。以前のアドレスを保存したブックマークより、起動ファイルから開く方法をおすすめします。

## Macで起動を許可する方法

Macでは、次の2種類の確認が別々に出る場合があります。表示された文に合う方を行ってください。

### A. 「実行する権限がない」と表示される

起動ファイルに実行権限を付けます。通常は最初の1回だけ必要です。新しいZIPを展開したときは、再度必要になる場合があります。

1. Finderで、展開したフォルダ内の **「高校入試コーチ.command」** を表示します。
2. Macの「ターミナル」を開きます。Spotlight検索で「ターミナル」と入力して探せます。
3. 次の文字を入力し、**最後に半角スペースを1つ追加**します。まだEnterは押しません。

   ```bash
   chmod u+x
   ```

4. Finderの **「高校入試コーチ.command」そのもの**を、ターミナルの入力行へドラッグします。ファイルの場所が自動入力されます。
5. Enterキーを押します。**エラーが出ず、次の入力行に戻れば通常は成功です。**
6. Finderへ戻り、起動ファイルをダブルクリックします。

入力結果の例は次の形です。場所は人によって異なるため、この例をそのままコピーせず、ドラッグで指定してください。

```text
chmod u+x /Users/あなたのユーザー名/Downloads/exam-coach/高校入試コーチ.command
```

`No such file or directory` はファイルの場所が違う場合、`usage: chmod ...` は入力方法が違う場合に表示されます。半角スペースを確認し、ファイルをドラッグし直してください。`sudo`や`chmod 777`は、この手順では使いません。

### B. 「開発元を確認できない」「Appleは検証できません」と表示される

これはAの実行権限とは別の、macOSの安全確認です。今回の配布版はAppleの署名・公証を受けていません。**正しい配布元から入手した、改変されていないファイルであることを確認した場合だけ**、次の操作を行います。

1. 「高校入試コーチ.command」をダブルクリックして警告を表示させます。
2. 警告を閉じます。「ゴミ箱に入れる」は選びません。
3. ** → システム設定 → プライバシーとセキュリティ**を開きます。
4. 下へスクロールし、「セキュリティ」にあるブロックされたファイル名を確認します。
5. **「このまま開く」**を選びます。macOSの版によっては、先に「開く」を選びます。
6. MacのログインパスワードやTouch IDで承認し、確認画面に従って開きます。

ボタンが出ない場合は、もう一度起動ファイルを開いて警告を表示させてから設定を確認します。「このまま開く」は起動を試した後、約1時間表示されます。Mac全体のセキュリティを無効にする操作は不要です。

「マルウェア」「コンピュータに損害を与える」など、ここで説明したものと違う警告の場合は、そのまま開かず、正確な文面と配布元を確認してください。

[Apple公式：開発元が不明なMacアプリを開く](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)

## うまく動かないとき

**データフォルダを削除してやり直す必要はありません。** まず表示された内容で切り分けます。

| 表示・症状 | 対処 |
| --- | --- |
| 「Node.jsが見つかりません」 | Node.js 24以上を導入し、起動ウィンドウを開き直します。 |
| 実行権限・Appleの確認で止まる | 上の「Macで起動を許可する方法」を確認します。 |
| 「設定処理に失敗しました」 | ネット接続と空き容量を確認し、再度起動してメニュー2を実行します。失敗直前のエラーも確認してください。 |
| 「起動を確認できませんでした」 | 起動ウィンドウを閉じて再度開き、メニュー2「初回設定・更新」を実行します。完了後に再度開き、1で起動します。 |
| 「ポート3000の使用状況と初回設定を確認してください」 | 旧版の可能性があります。HPからv0.2.1以降を入手し、新しく展開したフォルダの起動ファイルを使ってください。 |
| 「起動しました」と出たがブラウザが開かない | その行のURLをブラウザへコピーします。番号を3000に書き換えないでください。 |
| ブラウザに「接続できません」と出る | 起動ウィンドウが動いているか確認します。起動し直した場合は、新しく表示されたURLを使います。 |
| 「起動中または別の操作中です」 | 別の起動ウィンドウがないか確認し、そちらで正常に終了してから開き直します。 |
| 「Enterキーで閉じます」と出る | 操作終了時にもエラー時にも出る案内です。原因は、その直前の表示を確認してください。 |

### 停電・強制終了の後だけ「操作中」が消えない場合

正常に動いているアプリがないことを確認するため、まずパソコンを再起動します。それでも同じ表示が出る場合だけ、次の手順を行います。

1. 起動メニューの **5：保存先を表示**で、データの保存場所を確認します。
2. そのフォルダをFinderやエクスプローラーで開きます。
3. **`.operation-lock` フォルダだけ**を削除します。Macで見えない場合は、Finderで `Command + Shift + .` を押すと隠しファイルを表示できます。
4. 起動し直します。

アプリが動いている間は、このフォルダを削除しないでください。**`current` と `backups` は学習データなので削除しません。** 分からない場合は、この操作をせず、表示されたエラーを確認してください。

問い合わせる場合は「MacかWindowsか」「使っている版」「選んだメニュー番号」「エラーの文面」を伝えてください。氏名・成績・AIの回答全文や、データフォルダは送らないでください。

## 学習の進め方

1. **ニックネームと学年を登録**します。中学校名は任意です。
2. **第1・第2志望**を必要に応じて設定します。
3. **5教科のテスト結果**を入力します。
4. **学習アンケート**に回答します。
5. **優先教科と、その理由**を確認します。
6. **一週間の計画を編集・確定**します。
7. **実施結果と復習結果を記録**し、次週の調整につなげます。

分析・計画は決められたルールで作成します。AIを使わなくても、この流れを利用できます。問題集はブラウザの印刷画面からPDFとして保存できます。

詳しい画面操作は、アプリ内の「操作マニュアル」を開いてください。

## AIを使う場合

AIとの連携は任意です。自分で選んだAIサービスへ、手動で受け渡します。

1. アプリで、解析または類似問題の**プロンプト（AIへの依頼文）**を作成します。
2. 依頼文や添付資料に個人情報が残っていないか確認します。
3. 自分のAIサービスへコピーして貼り付けます。
4. AIから返った **JSON（アプリが読み込める形式の回答）**をコピーするか、`.json` ファイルで保存します。
5. アプリの対応する結果入力画面へ貼り付けるか、ファイルを読み込みます。
6. 内容を確認・修正し、承認してから反映します。

解析用と類似問題生成用では、回答の形式が異なります。依頼した画面に対応する結果入力画面を使ってください。説明文を含む回答全体ではなく、指定されたJSON部分を取り込みます。

**外部AIへ貼り付けた内容は、そのサービスへ送信されます。** アプリから自動送信はしませんが、テスト名・問題文・画像などの個人情報を完全に自動除去する機能ではありません。氏名や学校名などは、送る前に自分で確認・削除してください。

## バックアップと復元

### バックアップを作る

バックアップは、データを元に戻すための控えです。正常終了時に自動で作られます。手動で作る場合は、アプリを終了してから起動メニューの **3：バックアップ**を選びます。

成績、計画、AI連携の記録、添付資料、出力物をまとめて保存します。バックアップは自動削除しません。

**パソコン内の控えだけでは、端末の故障に備えられません。** 保存先の `backups` を開き、必要なバックアップのフォルダ全体を、自分で保管するUSBメモリなどにもコピーしてください。中のファイルを抜き出したり、名前を変えたりせず、フォルダごと保管します。

### バックアップから戻す

1. アプリを終了します。
2. 起動メニューの **4：復元**を選びます。
3. 表示された一覧から、戻したいバックアップの番号を入力します。
4. 対象を確認します。**現在の成績・計画・AI連携の記録・添付資料・出力物が、選んだ時点の内容に置き換わります。**
5. 戻す場合だけ、半角で **`RESTORE`** と入力してEnterを押します。
6. 完了表示を確認します。

復元前には、現在の状態も緊急バックアップとして保存します。破損や欠損を検出したバックアップは復元しません。

## アプリの更新とパソコンの買い替え

### 新しい版へ更新する

1. 使用中のアプリを正常終了します。
2. 新しいZIPをダウンロードし、**古い版とは別のフォルダ**へ展開します。
3. 新しいフォルダの起動ファイルを開き、**2：初回設定・更新**を選びます。
4. 設定完了後、起動ファイルを開き直し、**1：起動**を選びます。
5. これまでのデータが表示されることを確認します。

同じパソコン・同じOS利用者で、保存先を変更していなければ、これまでのデータを引き続き使います。更新前にバックアップを作成します。以後は**新しいフォルダの起動ファイル**を使ってください。

### 別のパソコンへ移す

1. 移行元でバックアップを作り、そのフォルダ全体を自分の外部媒体へコピーします。
2. 移行先に同じ版または新しい版を導入し、メニュー2で初回設定を済ませます。
3. 移行先のメニュー5で保存先を確認します。
4. その中の `backups` に、自分のバックアップフォルダをコピーします。
5. メニュー4で復元します。
6. メニュー2で設定・更新を行い、メニュー1で起動します。

複数のパソコンを自動同期する機能はありません。

### 旧「いわき高校入試コーチ」を使用していた方へ

旧版の保存先と、新しい個人端末版の保存先は別です。旧版のデータを自動で移動・削除しません。旧版の `manifest.txt` 形式のバックアップは、この復元メニューでは読み込めません。移行する場合は、先に旧版でバックアップを取り、専用の移行作業を行ってください。

## 保存場所と個人情報

保存先は、起動時の表示またはメニュー **5：保存先を表示**で確認できます。

| 環境 | 標準の保存先 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\exam-coach` |
| Mac | `~/Library/Application Support/exam-coach` |

MacではFinderの「移動」→「フォルダへ移動」に上のパスを貼り付けると開けます。Windowsではエクスプローラーのアドレス欄に貼り付けます。保存先を変更している場合は、メニュー5の表示を使ってください。

- **`current`：** 日常使用する学習データと添付資料・出力物。
- **`backups`：** 過去のバックアップ。
- **`logs`：** 障害確認用の記録。

アプリとデータは別のフォルダに保存します。アプリのフォルダだけを消しても、学習データは消えません。

このアプリにはログインやDBの暗号化がありません。同じOSアカウントを使う人はデータへアクセスできるため、パソコンの画面ロックと利用者アカウントで管理してください。データやバックアップを共有フォルダへ置かないでください。OSやクラウドサービス側の自動同期・バックアップ設定も、自分で確認してください。

生徒データの削除は、アプリ内の対象・影響を確認する画面から行います。削除しても過去のバックアップには残るため、不要なバックアップは別途自分で整理してください。

## 開発者・配布担当者向け

通常の利用では、以下のコマンド操作は不要です。

### 設計と開発

分析は `priority-v3`・`learning-tendency-v1`、計画は `weekly-plan-v2` の固定ルールです。Next.js、TypeScript、Prisma、SQLite、Zod、Recharts、Vitestなどを使用します。開発・テストでは架空データのみを使います。

開発時は `.env.example` を `.env` にコピーし、開発用の保存先を設定してから実行します。

```bash
npm ci
npm run db:migrate
npm run dev
```

品質確認と配布ZIPの作成：

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run package:local
```

テストには、127.0.0.1で一時的なサーバーを起動するポート競合試験を含みます。実行環境がローカル接続を制限している場合は、許可された環境で実施してください。

### HPで配布するファイル

`npm run package:local` で **`dist/exam-coach-personal.zip`** を作成します。HPへ掲載する際は、版を区別できるファイル名（例：`exam-coach-personal-v0.2.1.zip`）にして掲載できます。

ZIPにはプログラム・設定例・設計資料・テストを収録します。実環境設定、DB、添付資料、ログ、バックアップ、作業成果物は含めません。**使用済みの作業フォルダや、学習データの保存先をそのままZIP化して配布しないでください。**

HPには、版番号、Node.js 24以上が必要なこと、Macで確認済み・Windows実機未確認であること、スマホ未対応を記載してください。ZIPの配布と、学習データを扱うアプリの公開は別です。アプリ自体はlocalhost限定で使用し、LANやインターネットへ公開しません。

### 上級者向けの設定

- `EXAM_COACH_DATA_DIR`：データを保存する専用フォルダの絶対パス。共有・同期フォルダは指定しません。
- `EXAM_COACH_PORT`：優先する開始ポート。1024〜65535の整数。使用中なら自動で別の空きポートを選びます。
- 既定では3000番から10ポートを順に確認し、空きがなければOSが割り当てる番号を使います。空き確認直後の競合も再試行します。
- Linuxの標準保存先は `$XDG_DATA_HOME/exam-coach`、未設定時は `~/.local/share/exam-coach` です。Linux実機確認は未実施です。
