APP DEVELOPMENT

じぶんばす

開発環境 Xcode現在 実機テスト / TestFlight配布対応紹介動画 作成済み

バスで出かける人の「降りる場所が近づいたら知らせてほしい」を支えるiOSアプリ。登録したバス停などの地点に近づくとGPSで検知し、通知・音・振動で知らせます。軽度知的障害のある人、高齢者、ひとりでの移動に不安がある人にも使いやすいよう、ひらがなを中心にした分かりやすい表示と、やわらかなパステル調の画面、誤操作しにくい操作を大切にしています。

じぶんばす 紹介動画30 SEC MOVIE

「じぶんばす」の目的と使い方を、30秒で紹介しています。

MAIN FEATURES / 主な機能

  • 登録した地点へのGPS接近通知
  • 通知距離のカスタマイズ
  • 音・振動によるお知らせ
  • ワンタップでの通知停止とスヌーズ
  • 複数地点・グループの登録
  • 注意事項や写真の表示

DEVELOPMENT / 開発中

SwiftUI、CoreLocation、UserNotifications、MapKitを使い、既存のXcodeプロジェクトをベースに開発中。実機でのGPS監視や通知、権限取得、端末内保存などを確認しながら、Version 1.0とTestFlight配布に向けて調整しています。

実機テストとTestFlight配布対応アプリの目的や基本的な使い方が伝わる説明動画も作成。実際の端末で「登録する → 移動する → 近づいたら知らせる」という流れを確認しながら、通知の分かりやすさと操作のしやすさを詰めています。

APP DEVELOPMENT

あといくら？（仮称）

対応端末 iPhone / iPad現在 開発版 / 動作確認中

自分のお金を、自分で決める。

「あといくら？」は、自分で使うお金や目標を決め、「つかった」「はいった」を記録できるiPhone・iPad向けアプリです。のこりのお金を確かめ、1日の終わりや月のふりかえりも自分のペースで。必要なときだけ、選んだ相手と記録を共有できます。

開発版のご案内現在は開発版として動作確認を進めています。一般配布の時期・方法は未定です。画面や仕様は今後変更する場合があります。
あといくら？ 開発版紹介動画46 SEC MOVIE

開発版のテスト画面を使って、主な機能をご紹介します。約46秒・字幕付き・音声なし。画面の日付や金額は例です。家族専用アカウントや閲覧制限はありません。

動画はテスト画面のスライドによる紹介です。連続した操作の録画ではありません。
